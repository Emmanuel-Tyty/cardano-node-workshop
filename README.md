# Cardano Stake Pool Operator Workshop

Welcome to the Cardano SPO workshop. This repository contains everything you need to set up a relay node and register a stake pool on the Preview testnet.

## Quick Start

1.  **Preparation**: Complete the [Attendee Prerequisites](attendee-prereqs.md) before the session.
2.  **Workshop**: Follow the [Step-by-Step Guide](guide.md) during the session.

## Key Files

- `guide.md`: The consolidated workshop instructions.
- `attendee-prereqs.md`: System requirements and pre-sync instructions.
- `bootstrap-mithril.sh`: Automation script for fast node syncing.
- `docker-compose.yml`: Consolidated Docker setup for both Relay and BP nodes.
